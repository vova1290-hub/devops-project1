# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это лёгкий указатель на коммит, поэтому она создаётся почти мгновенно и не копирует файлы. В SVN ветвление обычно связано с копированием структуры каталогов в централизованном репозитории, поэтому оно сильнее зависит от сервера и сети.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Обычно нельзя. SVN — централизованная система, поэтому для коммита требуется соединение с центральным сервером. В Git коммиты сохраняются локально и могут быть отправлены на сервер позже.

## 3. Когда SVN может быть предпочтительнее Git?

SVN может использоваться в старых корпоративных проектах, где уже существует соответствующая инфраструктура. Также он может быть удобен при централизованном контроле доступа к отдельным каталогам и при работе с большими бинарными файлами.
